## Brand & Style

This design system expresses a high-performance, dark cyber-tactile aesthetic engineered for ultra-responsive low-latency remote interactions (WiFi Keyboard & Mouse bridging Android handhelds and Windows 11 host machines). 

The target audience comprises power users, PC gamers, software engineers, and media center operators who demand absolute precision, instant perceptual feedback, and dependable hardware telemetry. The UI evokes the mechanical satisfaction of a premium physical input device combined with the sleek telemetry of advanced diagnostic avionics.

Visual hallmarks include:
- **Deep layered slate-zinc chassis architecture** providing an OLED-friendly, low-fatigue workspace.
- **Physical keycap dimensionality** simulated through precise inner-glow rim lights and distinct press depths.
- **Chroma-telemetry accents** delivering instantaneous, peripheral-vision status validation (emerald for active links, cyan for cursor and key inputs, electric violet for mode shifts).
- **Haptic-synchronized feedback design** using localized energy rings, crisp edge highlights, and high-frequency tactile transitions.

## Colors

The palette pairs a cavernous, low-noise chassis with high-intensity luminescent markers. The base surface is deeply grounded in zinc-slate values to conserve battery and eliminate distraction in dim environments.

### Signal & State Colors
- **Primary (`#00f0ff` / Cyber Cyan):** Primary vector for transient input actions, touch-pad track trails, mouse button down states, and active pointer tracking.
- **Secondary (`#05ffa1` / Emerald Link):** Telemetry status indicator reserved strictly for sub-5ms low-latency active links, stable socket states, and packet delivery confirmation.
- **Tertiary (`#b026ff` / Electric Violet):** Modifier status flags, layer switching (NumPad, Media, GamePad mode), macro executions, and profile transitions.
- **Neutral Chassis (`#090a0f` / Obsidian Void):** Base background level. Nested tiers build upward through `#12141c` (chassis wells), `#181b26` (surface plate), and `#222634` (resting keycaps).

### Critical Functional Colors
- **Telemetry Amber (`#ffb800`):** Jitter alerts, buffer spikes, and dynamic link renegotiation (>25ms).
- **Telemetry Crimson (`#ff2a55`):** Socket drops, Windows service disconnects, or authentication failures.

## Typography

The typographic hierarchy uses a triad structure:
1. **Space Grotesk** anchors primary device headers, profile displays, and modal viewports with mechanical, wide-aperture geometry.
2. **Geist** guarantees neutral, razor-sharp clarity for dense setting panes, onboarding instructions, and contextual dialogues.
3. **JetBrains Mono** powers real-time metrics (RTT latency, payload size, FPS, keyboard legends, keystroke buffers, and raw hex codes). All monospaced readouts maintain tabular figures (`tnum`) to eliminate micro-jitter during dynamic telemetry streaming.

## Layout & Spacing

The interface accommodates rapid dual-thumb input, multi-touch gestures, and rapid view switching between full keyboard, precision trackpad, and mixed media controllers.

- **Grid Model:** Fluid modular layout utilizing safe-area dynamic framing. Key matrices adapt strictly via proportional column-span calculations to ensure ergonomic reach within the lower 60% of handheld touch displays.
- **Breakpoints & Adaptation:**
  - **Compact Handheld (< 480px):** Single-view focal layout. Tab-swappable surface modes (Trackpad / Full QWERTY / Numpad / Shortcuts). Edge margins set to `margin` (1rem) with micro-gap (`0.375rem`) key separation to maximize hit-target area.
  - **Medium / Foldables (481px - 840px):** Split-deck ergonomics. Left thumb dedicated to modular navigation/D-pad/modifiers; right thumb dedicated to high-precision trackpad or primary action clusters.
